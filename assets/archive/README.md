# AKASHI Archive assets

Upload collection artwork into the matching numbered collection folder below. Keep filenames lowercase, use hyphens, and include the sequence number where useful (for example `01-cover.jpg`, `02-artwork-name.jpg`). Recommended formats: JPG or WebP for photographic/raster artwork; PNG for transparency. Upload the highest practical quality. Do not upload ZIP files.

Each collection folder is intended to contain its cover image and all artwork belonging to that collection. The website will use these files for the expandable collection gallery and full-screen image viewer.
